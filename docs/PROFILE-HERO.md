# HOX3R Profile Hero

The profile banner is a monochrome, responsive ASCII portrait generated from the supplied avatar. It uses only white characters on a black background.

## Animation sequence

1. Characters enter from the nearest outer edge and assemble into the portrait.
2. After the portrait is assembled, a horizontal scan line passes over it.
3. The cycle repeats. Browsers honoring `prefers-reduced-motion` receive a static assembled portrait.

The desktop banner places the portrait beside the existing profile identity and focus areas. The mobile banner stacks the portrait above the focus labels. The profile README text and project descriptions are maintained separately in `README.md`; no project or experience claims are generated by the artwork script.

## Regenerate

Requires Python 3.10+ and the packages in `requirements.txt`.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/generate_profile_hero.py --source assets/source/portrait.png
python scripts/generate_profile_hero.py --source assets/source/portrait.png --check
```

Generated files:

- `assets/hero/hox3r-hero-desktop.gif`
- `assets/hero/hox3r-hero-mobile.gif`
- `assets/hero/hox3r-hero-desktop.svg`
- `assets/hero/hox3r-hero-mobile.svg`
- `assets/hero/hox3r-hero-desktop-preview.png`
- `assets/hero/hox3r-hero-mobile-preview.png`

The GIF files are embedded in the README for reliable animation on GitHub. SVG versions are also included as scalable editable source assets. PNG files are static review previews.

## Portrait privacy

`assets/source/portrait.png` is retained as a local generator input and ignored by Git. Do not force-add it to the public profile repository. Only publish the generated SVG and preview assets.

Check before committing:

```bash
git status --short
git check-ignore -v assets/source/portrait.png
```

GitHub may cache profile images. After publishing, allow time for its image proxy to refresh and verify the banner on the profile page.
